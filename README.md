# 🏥 Healthcare Analytics Dashboard Using Power BI

## 📊 Project Overview
This project focuses on analyzing healthcare data using Microsoft Power BI to generate insights into patient demographics, treatment patterns, hospital performance, and recovery outcomes.

Two healthcare datasets were combined and transformed to build an interactive dashboard that helps hospitals understand trends, improve operational efficiency, and support data-driven healthcare decisions.

---

## 🎯 Business Objectives
- Analyze patient demographics and medical conditions
- Evaluate treatment patterns and hospital service usage
- Identify admission and discharge trends
- Analyze treatment costs and recovery outcomes
- Support strategic healthcare planning using data analytics

---

## 🛠 Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Modeling
- Interactive Dashboard Design

---

## 📂 Datasets Used
1. **Patient Medical Records Dataset**
   - Age, Gender, Diagnosis
   - Admission & Discharge Dates
   - Blood Type & Medical History

2. **Hospital Treatment Details Dataset**
   - Treatment Type & Procedures
   - Doctor Information
   - Treatment Costs & Departments
   - Recovery Ratings

---

## 🔄 Data Preparation Process

### 📥 Data Import & Examination
- Imported datasets into Power BI
- Checked missing values & duplicates
- Validated column formats & data types

### 🔗 Data Modeling
- Merged datasets using common patient key
- Built relationships between tables
- Verified merged dataset accuracy

### 🧹 Data Cleaning
- Removed duplicate & irrelevant data
- Handled missing values
- Standardized categorical columns

### 🔢 Data Transformation
- Converted admission & discharge dates
- Calculated Length of Stay
- Created Age Group categories
- Built DAX measures for cost & recovery analysis

## 📌 Key Insights
- Adult patients form the largest demographic group
- Recovery ratings remain consistent across age groups
- Riverside Hospital shows strong recovery with lower cost
- Longer stays generally increase treatment cost
- No strong seasonal admission pattern observed
- Counseling & Medication treatments show strong recovery performance
